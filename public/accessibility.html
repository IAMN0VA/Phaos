Current support

The interface includes visible keyboard focus, a skip link to the imaging workspace, keyboard-accessible buttons, live status regions, reduced-motion support, textual safety notices, and labels that do not rely only on colour.

Imaging limitations

Medical images and interactive 3D content are inherently visual. Text descriptions and anatomy labels can support learning, but they do not fully reproduce the information in a scan. The application should not claim complete screen-reader equivalence for pixel data or 3D rendering.

Study mode

Study Mode can visually hide reference names as a learning exercise. This is a visual study feature only; underlying controls remain labelled for assistive technologies so accessibility is not intentionally reduced.

Feedback

The production operator should provide an accessibility contact before public launch and document any known barriers identified during keyboard, zoom, contrast, reduced-motion, and screen-reader testing.
