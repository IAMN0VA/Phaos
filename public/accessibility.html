Accessibility

Target: WCAG 2.2 AA for the web interface
ViewerPrivacyIntended useTerms

Implemented

  • Keyboard-visible focus indicators and a skip-to-workspace link.
  • Reduced-motion support that disables the decorative dust animation.
  • Live regions for loading, status, and error messages.
  • Dark interface with text labels in addition to color-coded states.
  • Keyboard shortcuts for common imaging tools.

Known limitations

Medical-image canvases are highly visual and cannot convey the scan itself through conventional text alternatives. Full assistive-technology conformance requires manual testing with keyboard-only navigation, VoiceOver/NVDA, zoom, contrast, and multiple display sizes before public release.

Feedback

A production operator should publish an accessibility contact and remediation process.
